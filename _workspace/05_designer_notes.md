## 4. 4면 레이아웃 결정

### 1면 — 5단 → 2영역 (1.7fr + 1fr)
- 좌측 메인 톱 + 우측 사이드 컬럼.
- 메인 톱 본문은 다시 **2단 멀티 칼럼**으로 쪼개 신문 다단 그리드 밀도를 살림.
- 본문 14줄 요약은 **번호 칩(원형 진홍 보더)** 부착해 카운트 가독성↑.
- "오늘의 요약" 박스는 사이드 컬럼 하단, 일자별 진홍 칩(`<span class="date">04/27</span>`)으로 5일 흐름 한눈에.
- **드롭캡 56px 진홍**으로 인쇄 신문 1면의 시그니처 무드.
- 면 인덱스 바(상단·하단 더블 라인) + 발행인의 말(이탤릭 + 진홍 따옴표).

### 2면 — 2영역 (2fr + 1.3fr)
- 좌측 외교 톱 + 우측 진영표.
- **진영표** 처음에 3컬럼(진영/입장/인용) 설계 → 우측 폭 제약으로 **2컬럼(진영 / 입장+인용 통합)**으로 변경. 인용은 이탤릭 + 출처 라벨(진홍) 분리로 위계 유지. 9개 진영 모두 좌측에 진홍 플래그.
- **제재 표**는 `nth-child(even)` 줄무늬와 일자 셀 진홍(Playfair Display)으로 신문지 표 톤. 7건 표시.

### 3면 — 3영역 (1fr + 1.5fr + 1fr)
- 사설 / 분석 / 한반도 박스.
- **사설 박스** = `--paper-warm` 배경 + 좌상단 EDITORIAL 진홍 라벨(absolute) + ::first-letter 38px 진홍 드롭캡.
- **분석 본문** 시나리오 A/B/C는 `.scenario` 클래스(좌측 진홍 보더 + 회색 배경)로 시선 강조.
- **한반도 박스** = 진홍 보더 + 일련번호 칩(decimal-leading-zero "01~10") + 굵은 라벨로 정부·산업·재외국민 한눈에 보임.

### 4면 — 인포그래픽 4종 + 메타 박스
- **No.01 5일 타임라인** (직접 SVG, 1140×380): 가로축 6점(4/27~5/2), 위/아래 더블 라벨로 사건 1~3건 배치. 5/1 DAY 63 박스만 강조 색(`--paper-warm`+굵은 진홍 보더). 색상: **군사·제재=진홍, 외교=검정, 시장=금색(#daa520), 발행일=빈 원**.
- **No.02 브렌트유 차트** (직접 SVG, 380×220): 100~130달러 스케일, 4/30 와타임 하이 점만 진홍·테두리·점선 가이드, 면 채움(opacity 0.08)으로 진홍 그라데이션.
- **No.03 호르무즈 모식도** (직접 SVG, 380×220): 상단 이란(연갈색)·하단 오만·UAE(짙은 갈색)·중앙 해협. 미 해군 1차 봉쇄선 진홍 X, 2차 통제구역 주황 X, USS CSG 픽토그램. 상·하단 컬러 바(헤더=진홍, 푸터=검정)로 시점 분리.

## 6. 인쇄·반응형

- `@media print { @page { size: A3 portrait; margin: 1cm; } }` 적용.
- 4면 사이에 `.page-break { page-break-after: always; }`.
- A3 인쇄 시 폰트 크기 강제 조정: 톱 헤드라인 54px→44px, 마스트헤드 84px→70px.

## 7. 편집안 준수 사항

- **헤드라인·본문·사설·인용 텍스트 일체 무수정**. 시각 디자인만 적용.
- 정병하 직위 "외교장관 특사(전 주쿠웨이트 대사)" 정정본 그대로 사용.
- **D등급 5건 양측 병기** — 사상자 표 `.discrepancy` 행 / 인용·시점·매체 별기 모두 유지.
- 모든 기사에 바이라인(by 종군기자 / 외교기자 / 편집장)과 출처 박스(`.source-box`) 부착.
- 사진은 **점묘 패턴 회색 placeholder + "[사진]" 라벨 + 캡션**. 실제 이미지 없음(저작권).
