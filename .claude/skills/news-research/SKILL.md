# 뉴스 취재 스킬 (News Research)

전쟁·국제 뉴스 취재의 표준 절차를 제공한다. 종군기자(war-correspondent)와 외교기자(diplomatic-correspondent)가 사용한다.

## 1. 검색 전략

### 1단계: 광역 스캔 (각 영역 3~5회 검색)
시간 범위를 좁힌 쿼리로 시작한다. **현재 날짜 2026-05-02 기준 최근 5일.**

좋은 쿼리 예시:
- `"Iran" attack OR strike May 2026`
- `Iran Israel war latest 2026-05`
- `Hormuz strait shipping April 2026`
- `Iran sanctions UN Security Council May 2026`
- `oil price Brent Iran tension this week`

피할 쿼리:
- "Iran war" — 너무 광범위, 과거 결과 혼입
- 연도 누락 — 오래된 결과 노출

### 2단계: 출처별 심화 (WebFetch)
광역 스캔에서 발견한 핵심 기사 URL을 WebFetch로 직접 읽어 본문 확보. 헤드라인만 보고 인용하지 말 것.

### 3단계: 양측 출처 교차
서방 1차(Reuters/AP/AFP/BBC) + 역내(Al Jazeera/Times of Israel/Tehran Times) 양쪽을 모두 확인.

## 2. 출처 신뢰도 등급

| 등급 | 매체 | 취급 |
|------|------|------|
| **Tier 1** | Reuters, AP, AFP, BBC, Al Jazeera English, France24 | 단독 인용 가능 |
| **Tier 2** | NYT, WaPo, Guardian, FT, WSJ, Bloomberg | 단독 인용 가능 |
| **Tier 3** | Times of Israel, Tehran Times, IRNA, Press TV (양측 관영) | 반드시 Tier 1/2와 교차 확인 후 인용 |
| **Tier 4** | 익명 SNS, 텔레그램 채널, 해석 불가 영상 | **인용 금지** |
| **국내** | 연합뉴스(공식 인용 가능), 종합지(보조 출처) | Tier 2 수준 취급 |

## 3. 인용 형식

모든 사실은 다음 형식으로 인용한다:

```
{사실 진술}. ({출처매체} {YYYY-MM-DD} 보도, [URL])
```

예:
```
4월 29일 새벽 호르무즈 해협에서 유조선 1척이 피격됐다고 알려졌다. (Reuters 2026-04-29 보도, https://...)
```

복수 출처:
```
(Reuters/AP 2026-04-29 보도)
```

상충하는 수치:
```
사상자는 X측 발표 N명, Y측 발표 M명이다. (X측: ..., Y측: ...)
```

## 4. 시점 정규화

매체마다 시각 표기가 다르다(현지/UTC/매체 본사 시간). **모든 시각은 KST(한국 표준시)로 환산하여 보고서에 기록**한다. 환산이 불가능한 경우 원시 표기 유지하고 매체 출처 표기.

원문에 "어제(yesterday)", "오늘 새벽(early today)" 등 상대 표기가 나오면 매체 발행 시각 기준으로 환산.

## 5. 5일 윈도우 엄수

- 1차 취재 대상: **2026-04-27 00:00 KST ~ 2026-05-02 23:59 KST**
- 윈도우 외 사건은 "배경" 박스에 1~2문장으로만 언급
- 윈도우 외 사건이 1차 영향을 미치는 경우(예: 1주 전 공격에 대한 이번 주 보복) 짧게 컨텍스트 제공

## 6. 검증 가능성 체크리스트

보고서 제출 전 자체 점검:

- [ ] 모든 사실에 출처 매체명 + 날짜 표기됨
- [ ] 단일 출처 정보는 "(단일 출처)" 표기됨
- [ ] 정부 공식 발표는 "X측 주장(claim)" 형태로 인용
- [ ] 사상자·발사체 수치는 출처별 차이가 있으면 병기됨
- [ ] 인명·지명 영문 원문 확인됨
- [ ] 5일 윈도우 외 사건은 배경 박스 처리됨

## 7. 미검증 항목 처리

100% 검증되지 않은 항목은 **삭제하지 말고** 보고서 끝의 "미검증 주장 / 의문점" 섹션에 옮긴다. 팩트체커가 추가 검증할 수 있도록.

## 8. 보고서 마감 시각 가이드

- 광역 스캔 + 심화 취재: 본인 작업의 80% 시간 할당
- 교차 검증 + 정리: 20% 시간
- 마감 직전에는 "이 사건은 지금 시점에 다시 검색해야 하는가?" 자문하여, 신속 보도 가치가 있는 마지막 업데이트 1회 추가 검색

## 9. 한국어 보고 스타일

- 외국 인명·지명은 처음 등장 시 한글(영문) 표기, 이후 한글만
- 군사 용어는 한국에서 통용되는 번역 사용 (예: ICBM=대륙간탄도미사일, drone=무인기/드론)
- 직접 인용은 큰따옴표 + 한국어 번역, 핵심 단어는 (영문 원문) 병기
