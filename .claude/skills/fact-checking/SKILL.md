# 팩트체크 스킬 (Fact Checking)

전쟁·국제 보도에 특화된 팩트체크 방법론. fact-checker 에이전트가 사용한다.

## 1. 검증 대상 식별

기자 보고서에서 다음 항목을 **검증 대상 주장(claim)**으로 추출한다:

1. **사건 발생 사실** — "X가 Y를 공격했다", "Z가 발사됐다"
2. **수치** — 사상자, 미사일 수, 비용, 거리
3. **인용** — "고위 당국자 발언", 정부 성명문
4. **시점** — "X일에 Y가 발생"
5. **인과** — "A 때문에 B가 발생했다" (특히 신중)

배경 설명, 일반 상식, 명백한 사실(예: "이란은 페르시아만 인근 국가")은 검증 대상 아님.

## 2. 검증 절차

각 주장당 다음 4단계를 수행:

### Step 1: 출처 신뢰도 평가
기자가 제시한 1차 출처를 등급 분류 (`news-research` 스킬의 Tier 1~4 기준).

### Step 2: 독립 출처 확인
WebSearch로 동일 사건을 다른 매체에서 보도했는지 확인. 핵심 키워드(인명, 지명, 시각)로 영문 검색.

원칙:
- **독립 출처 = 통신사 인용 사슬이 다른 매체**. AP를 인용한 5개 매체가 보도했어도 독립 출처는 1개(AP).
- 정부 발표를 그대로 받아쓴 보도는 출처 다양성에 가산하지 않는다.

### Step 3: 일관성 점검
- 수치: 출처 간 차이가 있는가? (있으면 D등급 후보)
- 시점: 매체 간 시각 충돌이 있는가?
- 인명/지명: 영문 원문 표기가 일치하는가?
- 인과: 같은 사건에 대해 매체가 다른 원인을 제시하는가?

### Step 4: 등급 부여
| 등급 | 정의 |
|------|------|
| **A** | Tier 1/2 매체 3개 이상 일치 |
| **B** | Tier 1/2 매체 2개 일치, 또는 Tier 1 단독 보도 |
| **C** | 단일 출처(단일 매체 또는 한쪽 정부 발표만) |
| **D** | 출처 간 사실/수치 충돌 — 양측 주장 병기 권고 |
| **F** | 검증 출처 없음, 또는 명백한 오정보 / 과거 사진 재활용 의심 |

## 3. 자주 발견되는 함정

### 3-1. 정부 발표의 함정
- 양측 정부 발표는 **1차 사료지만 사실은 아니다**. 모두 C등급 처음 부여 후, 독립 매체 확인 시 상향.
- 사상자 발표는 정치적으로 부풀려지거나 축소된다 — 거의 항상 D등급.

### 3-2. 사진·영상의 함정
- 기자가 인용한 시각 자료가 **과거 사건 재활용**일 수 있다. 매체 캡션이 "AP/Reuters/AFP" 같은 통신사 워터마크가 있고 날짜가 명시되어 있는지 확인.
- "신원 미상 SNS" 영상은 자동 F등급.

### 3-3. 통신사 사슬의 함정
- 한 통신사가 오보를 내면 인용한 모든 매체가 같은 오류를 옮긴다. **다른 통신사**(AP vs Reuters vs AFP)에서도 보도되는지 반드시 확인.

### 3-4. 번역 함정
- 외국어 발언이 매체별로 다른 톤으로 번역될 수 있다. 핵심 단어는 영문 원문이 같은지 확인.
- 예: "regrettable"(유감) vs "outrageous"(분노) — 강도 차이 크다.

### 3-5. 시점 함정
- 매체 발행 시각과 사건 발생 시각을 혼동하지 말 것. "이번 주 발생"이 5일 윈도우 안인지 확인.

## 4. 검증 보고 형식

각 주장당:
```markdown
### [C-001] {주장 1줄 요약}
- **기자 보고**: {원문 발췌}
- **기자 인용 출처**: {매체, URL, 발행일시}
- **추가 확인 출처**:
  - {매체1, URL, 발행일시} — 일치/충돌
  - {매체2, URL, 발행일시} — 일치/충돌
- **충돌 내역**: (있을 시) 수치 X측 N명 vs Y측 M명, 시점 차이 등
- **등급**: A/B/C/D/F
- **편집부 권고**: 1면 톱 가능 / 본기사 가능 / "~측 주장" 표기 / 양측 병기 / 게재 보류
- **주석**: (필요 시 추가 맥락)
```

## 5. 검증 시간 배분

5일치 기자 보고서를 빠르게 검증해야 하므로:
- 톱 후보 5~10건: 각 주장당 3개 이상 출처 확인 (충실 검증)
- 본기사 후보 10~20건: 2개 출처 확인 (표준 검증)
- 박스/사이드 30건+: 1개 추가 출처 + 일관성 점검 (간이 검증)

## 6. F등급 즉시 보고

F등급 발견 시 보고서 완성을 기다리지 말고 즉시 editor-in-chief에게 SendMessage로 알린다. 톱기사 후보가 F등급이면 편집안 자체가 흔들리므로.

## 7. 검증 한계 명시

검증 가능 범위 밖의 항목은 솔직하게 표기:
- "독립 검증 불가 — 사건 지역의 매체 접근 제한"
- "수치 검증 불가 — 양측 모두 자료 비공개"

이런 항목은 자동 F등급 아니라, 등급 보류(N/A)로 표기하고 편집부에 판단 위임.
